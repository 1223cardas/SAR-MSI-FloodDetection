================================================================================
              SAR-MSI FLOOD DETECTION - INSTALLATION GUIDE
================================================================================

Flood detection project using Sentinel-1 (SAR) and Sentinel-2 (multispectral) 
products.

================================================================================
SYSTEM REQUIREMENTS
================================================================================

- Windows 10+ or Linux (Ubuntu 18.04+)
- Python 3.10+
- Java Runtime Environment (JRE) 8+ (required for SNAP)
- ~20 GB of free disk space (for satellite data storage)
- 8GB RAM+
- Internet connection to download data

================================================================================
STEP 1: PYTHON INSTALLATION
================================================================================

1. Check if Python is installed:
   - Open the terminal (Command Prompt or PowerShell on Windows)
   - Type: python --version
   
2. If you do not have Python:
   - Go to https://www.python.org/downloads/
   - Download Python 3.10+ (recommended)
   - Run the installer
   - IMPORTANT: Check the option "Add Python to PATH"

3. Verify the installation:
   - python --version
   - pip --version

================================================================================
STEP 2: CLONE/DOWNLOAD THE PROJECT
================================================================================

1. Navigate to the folder where you want to install the project:


2. Download the project:
   - If you have Git installed:
     git clone https://github.com/your-repo/SAR-MSI-FloodDetection.git
     cd SAR-MSI-FloodDetection
   
   - Otherwise, download the ZIP file and extract it

================================================================================
STEP 3: CREATE PYTHON VIRTUAL ENVIRONMENT
================================================================================

1. In the terminal, navigate to the project folder:
   cd SAR-MSI-FloodDetection

2. Create a virtual environment:
   python -m venv .venv

3. Activate the virtual environment:

   *** WINDOWS (Command Prompt) ***
   .venv\Scripts\activate.bat

   *** WINDOWS (PowerShell) ***
   .venv\Scripts\Activate.ps1
   (If you get a permissions error, run:
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser)

   *** LINUX ***
   source .venv/bin/activate

4. Confirm the environment is activated (you should see .venv in the prompt):
   (.venv) C:\Users\...\SAR-MSI-FloodDetection>

================================================================================
STEP 4: INSTALL PYTHON DEPENDENCIES
================================================================================

1. Update pip:
   python -m pip install --upgrade pip

2. Install the dependencies:
   pip install -r requirements.txt

================================================================================
STEP 5: INSTALL SNAP (REQUIRED FOR SENTINEL-1)
================================================================================

*** WINDOWS (Recommended) ***

1. Download ESA SNAP:
   - Go to https://step.esa.int/main/download/snap-download/
   - Click on "ESA SNAP" > Windows 64-bit installer
   - Download the (.exe) file

2. Run the installer:
   - Double-click the .exe file
   - Follow the instructions
   - Default installation (recommended): C:\Program Files\esa-snap

3. Confirm the installation:
   - Open a new terminal/PowerShell
   - Type: "C:\Program Files\esa-snap\bin\gpt.exe" -h
   - The SNAP version/help banner should appear

*** LINUX ***

1. Download SNAP:
   wget https://download.esa.int/esaup/sentinel/SNAP/esa-snap_all_linux-x86_64.tar.gz

2. Extract:
   tar -xzf esa-snap_all_linux-x86_64.tar.gz
   mv esa-snap ~/snap

3. Confirm:
   ~/snap/bin/gpt --diag

================================================================================
STEP 6: CONFIGURE .ENV FILE
================================================================================

1. In the project folder, copy the .env.example file:
   
   *** WINDOWS (PowerShell) ***
   Copy-Item .env.example .env
   
   *** LINUX ***
   cp .env.example .env

2. Open the .env file in a text editor (Notepad, VS Code, etc.):
   .env

3. Fill in the following variables:

   a) SNAP_DIRECTORY
      - Windows: C:\Program Files\esa-snap
      - Linux: /home/YOUR_USER/snap

   b) CDSE Credentials (Copernicus Data Space Ecosystem)
      1. Go to https://dataspace.copernicus.eu/
      2. Click "Register" or "Sign In"
      3. After logging in, go to "Account Settings"
      4. Copy your username
      5. Create/copy your password
      6. Add to .env:
         CDSE_USERNAME=your-username
         CDSE_PASSWORD=your-password

   c) Sentinel Hub Credentials (OAuth)
      1. Go to https://shapps.dataspace.copernicus.eu/dashboard/#/
      2. Log in with CDSE credentials
      3. Navigate to "OAuth Clients" or "API Keys"
      4. Click "Create new" or "New OAuth Client"
      5. Name: "SAR-MSI-FloodDetection"
      6. Type: "Confidential"
      7. Copy Client ID and Client Secret
      8. Add to .env:
         SH_CLIENT_ID=your-client-id
         SH_CLIENT_SECRET=your-client-secret

================================================================================
STEP 7: TEST INSTALLATION
================================================================================

1. Verify the Python environment:
   python --version
   pip install -r requirements.txt

2. Verify SNAP:
   [cmd]    "C:\Program Files\esa-snap\bin\gpt.exe" --diag
   [pws]    & "C:\Program Files\esa-snap\bin\gpt.exe" --diag
   [Linux]  /path/to/snap/bin/gpt --diag

3. Run unit tests:
   python -m pytest -v

================================================================================
STEP 8: USE THE PROJECT
================================================================================

Graphical User Interface (GUI):
   python app.py

Command Line Interface (CLI):
   python main.py

To deactivate the virtual environment when finished:
   deactivate
